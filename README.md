# Meridaxis Consulting – Web Sitesi

Antalya turizm işletmelerine yönelik danışmanlık firması Meridaxis Consulting'in tanıtım ve hizmet vitrini sitesi.

- Next.js 15 (App Router, statik export) + Tailwind CSS 4
- İçerik: `lib/content.ts` (hizmetler, süreç, SSS vb.)
- İletişim bilgileri: `lib/site.ts` (yayından önce güncellenmeli)

```bash
npm install
npm run dev     # geliştirme
npm run build   # statik çıktı: out/
```
